ทดสอบ QA จากคลิปที่เลือก

  1. อัปโหลดหรือเลือกคลิป แล้วดูว่าเกิดเหตุจริงเมื่อไร
  2. เช่น ล้มช่วงวินาที 3–4 ให้กรอกเริ่ม 3 จบ 4 แล้วกด “เพิ่มช่วงเหตุจริง”
  3. ถ้าคลิปไม่มีเหตุ ให้ติ๊ก “ฉันตรวจคลิปแล้ว ไม่มีเหตุ” แทน
  4. กด “เริ่มทดสอบทั้งคลิป” รอจบ แล้วดูจำนวนเจอ / พลาด / เตือนผิด และดาวน์โหลด JSON

ดูคลิปและระบุช่วงเหตุจริงก่อนทดสอบ ระบบจะเริ่มคลิปจากต้นจนจบ ไม่วนซ้ำ พักได้ แต่ต้องหยุด QA ก่อนกรอคลิป ผลเป็นการทดสอบคลิปที่ระบุ ไม่ใช่การรับรองความแม่นยำทั้งหมด
